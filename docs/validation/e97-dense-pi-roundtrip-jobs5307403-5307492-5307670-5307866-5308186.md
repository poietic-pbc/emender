## Initial failures and diagnosis

### Job 5307403

The first real Pi run reached the server but returned HTTP 422. Pi completed with an error and did not execute a tool. The server correctly failed closed because the generated turn did not begin with `Action:` or `Final:`.

Scheduler result: `FAILED`, exit `143:0`, `Partition=batch`, `QOS=debug`.

### Job 5307492

Opt-in generation diagnostics showed `generated_prefix=Cal`. This revealed that Pi had requested only one output token; `Cal` was the first token, not evidence that recurrent caching had destroyed the full response.

A local capture of Pi's actual provider payload identified two integration facts:

1. Pi reserves 4096 context tokens before clamping maximum output. Advertising a 4096-token context therefore forced `max_completion_tokens=1`.
2. Pi appended discovered skills and the working directory to the replacement system prompt.

Scheduler result: `FAILED`, exit `1:0`, `Partition=batch`, `QOS=debug`.

### Job 5307670

A legacy variable-length segment ingestion mode was tested before fixing Pi's one-token request and system decoration. It also emitted only `Cal`, confirming that changing recurrent ingestion mode did not address the actual protocol-budget defect.

Scheduler result: `FAILED`, exit `1:0`, `Partition=batch`, `QOS=debug`.

### Fix

Commit `043a85a3`:

- advertises an 8192-token window, leaving Pi's 4096-token safety reserve plus a bounded output budget;
- disables skills and context-file injection for the v1 qualification;
- allows an explicit server-side v1 canonical system override, removing Pi's runtime working-directory suffix from the model transcript;
- keeps harness runtime metadata out of the native training serialization.

This does not claim 8K semantic training. It gives Pi sufficient accounting headroom for the bounded <=4K model transcript and <=512-token response.

## Safety notes

The server binds to loopback by default and requires an API key for non-loopback binding. It bounds request bytes, output tokens, and active recurrent sessions. Unknown tools, malformed JSON arguments, parallel tool calls, unsupported message content, invalid sampling bounds, and incompatible cache prefixes fail closed. Generated-prefix diagnostics are disabled by default and require the explicit `--trace-generated-errors` qualification flag.

The v1 Pi extension does not expose child processes or shell access. Its file tools canonicalize existing paths through `realpath`, require them to remain under the task root, cap reads at 8192 bytes, and cap results at 256 entries.
