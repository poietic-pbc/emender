## Protocol change under test

These are the first MoE evaluations using the dense agent's current coherent-conversation protocol:

- no RS serialized between user, assistant, and tool turns;
- generation stops on one complete structured action;
- recurrence resets only between unrelated tasks;
- Pi owns tool execution and grounded termination;
- all model operations remain fused eight-way node-local expert parallel.

Earlier record-reset MoE studies did not test this complete protocol.
