## Concrete failure and root cause

Exact smoke job `4974391` allocated 256 nodes but failed `72:0` after two
seconds, before any `srun` step.  The retained runner evidence identifies the
last phase as `module-bootstrap` and the missing path as
`/etc/profile.d/modules.sh`.  A Slurm-like reproduction succeeds in removing
the inherited shell function (`env -i ... bash --noprofile --norc`), confirms
that `module` is absent, and confirms that `modules.sh` does not exist.

Frontier provides the site configuration at `/etc/profile.d/olcf-env.sh` and
Cray Lmod's shell initializer at `/opt/cray/pe/lmod/lmod/init/bash`.  Sourcing
those two files in the clean shell defines the same Lmod `module` function
used by the successful launch.

Job `4962400` passed because its batch launch inherited the exported Lmod
function.  Its common runner's conditional `modules.sh` fallback was dormant.
The immutable runner correctly strengthens the scheduler boundary to
`--export=NONE`, so it must explicitly initialize Lmod rather than depend on
that inheritance.
